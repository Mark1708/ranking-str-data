## Цель

CLI-инструмент для оценки TMRCA (время до наиболее недавнего общего предка) по Y-STR локусам с последующим ранжированием гаплотипов относительно базового гаплотипа. Создан для группы генетических исследований.

## Область применения

- Чтение CSV-файлов с данными Y-STR гаплотипов
- Вычисление генетических расстояний с использованием модели распределения Пуассона
- Ранжирование гаплотипов по близости к заданному базовому гаплотипу
- Поддержка настраиваемого параметра среднего возраста поколения
- Поддержка настраиваемой частоты мутаций на локус на поколение (флаг `--mu`, по умолчанию 0.0026)

## Алгоритм

Инструмент реализует линейный метод Клёсова (2009a) для оценки TMRCA по Y-STR с поправкой на обратные мутации:

1. **ASD** (Среднеквадратичное расстояние): `ASD = sum((ref_i - comp_i)^2) / n`, где n -- количество совпадающих локусов
2. **TMRCA**: `T = averageAge * ASD / mutationRate` (лет до настоящего времени)
3. **Lambda** (фактические мутации): `lambda = mutationRate * T_generations`, где `T_generations = T / averageAge`
4. **K** (наблюдаемые мутации с поправкой на обратные мутации): `k = (lambda / 2) * (1 + exp(-lambda))` (прямая формула Клёсова)

**Частота мутаций по умолчанию**: 0.0026 на локус на поколение (Ballantyne et al. 2010, средневзвешенное по 186 Y-STR маркерам).

**Выходные колонки**: Index, Loci (количество совпадений), TMRCA (лет), Lambda (фактические мутации), K (наблюдаемые мутации с поправкой на обратные мутации).

## Воспроизводимость

**Предварительные требования:** Java 21+, Maven

**Сборка:**

```bash
mvn clean package
```

**Тесты:**

```bash
mvn clean test
```

**Запуск:**

```bash
java -jar target/ranking.jar -p /path/to/DataSet.csv -i indexOfHaplotype -a averageAge
```

**С настраиваемой частотой мутаций:**

```bash
java -jar target/ranking.jar -p /path/to/DataSet.csv -i indexOfHaplotype -a averageAge --mu 0.0024
```

**Справка:**

```bash
java -jar target/ranking.jar -h
```

**Формат входных данных:** CSV, где первый столбец называется "Index", за которым следуют названия локусов.

Примечание: Первый столбец должен называться "Index", за которым следуют названия локусов.

## Предположения о входных данных

- Входные данные представлены в формате CSV с разделением точкой с запятой
- Первый столбец должен называться "Index"
- Значения локусов должны быть числовыми (целочисленные значения STR) при наличии
- Пустые/null значения пропускаются попарно при сравнении
- Базовый гаплотип, указанный индексом, должен существовать во входном наборе данных

## Размер набора данных

Этот инструмент обрабатывает CSV-файлы с разделителем "точка с запятой", содержащие данные Y-STR гаплотипов:

- **Типичный ввод**: 10-500 гаплотипов, 20-100 локусов на гаплотип
- **Память**: Инструмент загружает все данные в память для расчёта метрик. Для наборов данных более 10 000 строк убедитесь в достаточном размере heap JVM (`-Xmx`)
- **Режим Spark**: Работает в режиме `local[1]`. Spark обеспечивает инфраструктуру парсинга CSV; расчёт метрик выполняется в памяти на driver

При обработке очень больших наборов данных (>100k строк) используйте Spark-кластер с профилем thin-jar:

```bash
mvn clean package -Pthin-jar
spark-submit --class ranking.Main target/ranking.jar -p /path/to/data.csv -i index -a 30
```

## Ограничения

- Исследовательский/локальный CLI инструмент, не предназначен для production-использования
- Работает на Spark 4.1.2 в локальном режиме с Log4j 2.26.0
- Примеры и эталонные результаты являются поведенческими справочниками, а не производственными эталонами
- Формулы генетических расстояний не клинически валидированы для диагностических целей
- Формулы не должны изменяться без экспертизы и валидации домена
- Требуется Java 21+ (LTS)
- Все CSV-колонки читаются как строки для сохранения точности данных (ведущие нули в Index, точные значения локусов)
- Формула поправки на обратные мутации предполагает низкие частоты мутаций; точность снижается при lambda > 2
